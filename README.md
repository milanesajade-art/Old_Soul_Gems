# Old Soul Gem

Free GitHub Pages storefront for Old Soul Gem.

## Editing

- `catalog.js` controls collection names, jewelry descriptions, image positions, Etsy links, and social links.
- `index.html` controls page structure.
- `styles.css` controls visual design.
- `app.js` renders the catalog and interactions.

The current photography source is the archived Old Soul Gem repository. Replace it with direct high-resolution files in this repository as original images become available.
